# Setup for the `lz811` GitHub profile

All content inside `README.md` is in English. These setup instructions are in Russian for convenience.

1. На GitHub создай **публичный** репозиторий с точным именем `lz811` (то есть `lz811/lz811`). Если он уже существует, используй его.
2. Из архива перенеси `README.md`, папку `assets` и папку `.github` в корень этого репозитория, сохраняя пути и имена файлов.
3. Открой **Settings → Actions → General → Workflow permissions** и выбери **Read and write permissions** (если этот вариант доступен), затем сохрани.
4. Вкладка **Actions → Generate contribution snake → Run workflow**: запусти workflow вручную один раз.
5. После успешного запуска появится ветка `output`. README подхватит анимированную змейку из неё; затем она будет обновляться ежедневно.
6. GitHub автоматически покажет профильный README на `https://github.com/lz811`.

### Добавление проектов позже

В `README.md` найди комментарии `FEATURED_PROJECTS_START` и `FEATURED_PROJECTS_END`. Заменяй текущий плейсхолдер карточками проектов по мере готовности. Не нужно менять остальные секции.

### Важные замечания

- `assets/retro-computer-banner.png` и `assets/footer.svg` должны оставаться в репозитории. Один отдельный README без этих файлов не покажет оформление полностью.
- Статистика и анимация печатающегося текста подгружаются из сторонних публичных сервисов; иногда могут быть недоступны.
- Snake не появится до первого успешного запуска GitHub Actions.
- В зависимости от настроек репозитория GitHub может ограничивать права workflow; если автоматическая публикация не сработает, проверь разрешения в Settings.
- SVG-анимация в некоторых мобильных клиентах GitHub может выглядеть как статичная картинка.
